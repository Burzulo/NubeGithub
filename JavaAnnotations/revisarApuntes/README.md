# 🚀 Roadmap Profesional de Java: De Cero a Senior

Este índice representa el camino de aprendizaje profesional basado en la documentación oficial de Oracle (Java SE) y los estándares de la Eclipse Foundation (Jakarta EE).

---

## ☕ Bloque 1: Java Standard Edition (Java SE)
*Fundamentos del lenguaje y la Java Virtual Machine (JVM).*

### 1.1. Arquitectura y Entorno (The Core)
- **Ecosistema de Ejecución:** JDK vs. JRE, JVM y ciclo de vida del Bytecode.
- **Gestión de Memoria:** Stack Memory, Heap Memory y funcionamiento del Garbage Collector (GC).
- **Herramientas:** Compilación con `javac`, ejecución con `java` y uso de `JShell`.

### 1.2. Sintaxis y Estructuras Modernas
- **Tipado:** Primitivos vs. Wrappers (Autoboxing/Unboxing).
- **Control de Flujo:** Estructuras `if-else`, bucles y la evolución de `switch expressions`.
- **Texto:** Inmutabilidad de `String`, `StringBuilder` y `Text Blocks` (multilínea).

### 1.3. Datos y Resiliencia
- **Arrays:** Declaración y manipulación de matrices.
- **Excepciones:** Jerarquía de `Throwable` (Checked vs Unchecked) y bloques `try-with-resources`.
- **Generics:** Clases genéricas y el principio PECS (Wildcards).

### 1.4. Frameworks del Sistema
- **Collections Framework:** Listas, Sets, Maps y Colas (ArrayList, HashMap, etc.).
- **I/O & NIO2:** Manejo de archivos y flujos de datos.
- **Concurrencia:** Creación de hilos (Threads), `Runnable` y sincronización básica.

---

## 🧩 Bloque 2: Programación Orientada a Objetos (POO)
*Diseño de software modular y escalable.*

### 2.1. Modelado de Objetos
- **Clases e Instancias:** Atributos, métodos y el uso de `this`.
- **Ciclo de Vida:** Sobrecarga de constructores e inicialización estática.
- **Encapsulamiento:** Modificadores de acceso y diseño de API interna.

### 2.2. Los Pilares de la Ingeniería
- **Herencia:** Extensión de clases, uso de `super()` y la clase raíz `Object`.
- **Polimorfismo:** Sobrecarga (estático) y sobrescritura (dinámico con `@Override`).
- **Abstracción:** Clases abstractas vs. Interfaces (métodos `default` y `static`).

### 2.3. Tipos Especiales y Modernidad
- **Enums:** Enumeraciones con comportamiento y estado.
- **Records (Java 16+):** Modelado de datos inmutables sin código repetitivo.
- **Sealed Classes (Java 17+):** Control estricto de la jerarquía de herencia.

---

## 🌐 Bloque 3: Jakarta EE (Enterprise Edition)
*Desarrollo de aplicaciones empresariales escalables.*

### 3.1. Arquitectura Web
- **Servlets:** Manejo del protocolo HTTP y sesiones de usuario.
- **CDI:** Inyección de dependencias profesional y gestión de ámbitos (Scopes).
- **Bean Validation:** Validación de reglas de negocio en el modelo.

### 3.2. Persistencia y APIs
- **JPA (Jakarta Persistence):** Mapeo de bases de datos relacionales a objetos Java.
- **JAX-RS:** Construcción de servicios Web RESTful y consumo de JSON.
- **Transaccionalidad:** Manejo de integridad de datos en entornos distribuidos.
