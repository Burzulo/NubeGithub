# organizar

---------------------------------------------------------------------

🔖 Java Desktop (JavaFX)

Fundamentos y Arquitectura: ⇒

- El ciclo de vida de una aplicación JavaFX.
- El concepto de Escenario y Lienzo: Stage, Scene y el grafo de nodos (Nodes).
- Componentes básicos de interfaz (Botones, Textos, Campos de texto).

Diseño Visual y Maquetación: ⇒

- Uso de contenedores para organizar la pantalla (VBox, HBox, GridPane).
- Introducción a Scene Builder (Herramienta visual de arrastrar y soltar).
- Estructura de archivos FXML (El XML que define la vista).

Interactividad (El Patrón MVC en Desktop): ⇒

- Conexión de la vista FXML con el código Java mediante el archivo Controller.
- Uso de la anotación @FXML para referenciar componentes.
- Manejo de eventos: Qué pasa cuando el usuario hace clic o escribe.

Conceptos Avanzados: ⇒

- Enlace de datos (Properties y Bindings).
- Estilos visuales: Personalización de la interfaz usando CSS.
